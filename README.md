# 🚢 Batalha Naval

Projeto desenvolvido utilizando **HTML, CSS e JavaScript**, com o objetivo de recriar o clássico jogo de estratégia **Batalha Naval** em uma versão web interativa.

## 📚 Sobre o Projeto

Este projeto está sendo desenvolvido por **Lucas Piancó**, **Luis Gabriel** e **Carlos Eduardo** como parte de uma projeto da ETEC Bartolomeu Bueno da Silva.

O objetivo principal é aplicar conceitos de desenvolvimento web, lógica de programação, manipulação do DOM e organização de projetos utilizando tecnologias front-end.

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---

## 📌 Estrutura do Desenvolvimento

O projeto foi dividido em **duas etapas principais**:

### Primeira Parte — Base do Jogo

Nesta etapa foi desenvolvida toda a estrutura principal da Batalha Naval, incluindo:

- Construção do tabuleiro
- Lógica inicial do jogo
- Posicionamento de elementos
- Interações básicas
- Estrutura do projeto

---

### Segunda Parte — Melhorias e Diferenciais

Agora o projeto entra na fase de aprimoramento visual e funcional, onde serão adicionados:

- Estilização completa da interface
- Tela de login
- Melhorias na experiência do usuário
- Animações e efeitos visuais
- Diferenciais criativos para destacar o projeto

---

## 🎯 Objetivo

Além do aprendizado técnico, este projeto busca desenvolver:

- Trabalho em equipe
- Organização de código
- Criatividade
- Resolução de problemas
- Desenvolvimento de projetos reais para portfólio
